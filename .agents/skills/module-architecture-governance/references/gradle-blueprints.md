# Gradle Blueprints for Module Architecture

Use these blueprints when creating new modules. Replace placeholders like `[JAVA_VERSION]`, `[PACKAGE_NAME]`, `[COMPILE_SDK]`, `[MIN_SDK]`, and `[TARGET_SDK]` with the dynamically resolved values from the project.

## 1. The `:domain` Module (Pure Kotlin)
**File**: `domain/build.gradle.kts`
```kotlin
plugins {
    alias(libs.plugins.kotlin.jvm)
}

java {
    sourceCompatibility = JavaVersion.VERSION_[JAVA_VERSION]
    targetCompatibility = JavaVersion.VERSION_[JAVA_VERSION]
}

kotlin {
    compilerOptions { jvmTarget.set(org.jetbrains.kotlin.gradle.dsl.JvmTarget.JVM_[JAVA_VERSION]) }
}

dependencies {
    // JSR-330 for framework-agnostic DI
    implementation(libs.javax.inject)
    // Add other pure Kotlin libraries here (e.g., Coroutines)
}
```

## 2. The `:data` Module (Data Infrastructure)
**Type**: Android Library (No UI)
**File**: `data/build.gradle.kts`
```kotlin
plugins {
    alias(libs.plugins.android.library)
    alias(libs.plugins.kotlin.android)
    // Add KSP if using Room or Hilt: alias(libs.plugins.ksp)
}

android {
    namespace = "[PACKAGE_NAME].data"
    compileSdk = [COMPILE_SDK]

    defaultConfig {
        minSdk = [MIN_SDK]
        testInstrumentationRunner = "androidx.test.runner.AndroidJUnitRunner"
    }

    compileOptions {
        sourceCompatibility = JavaVersion.VERSION_[JAVA_VERSION]
        targetCompatibility = JavaVersion.VERSION_[JAVA_VERSION]
    }
}

kotlin {
    compilerOptions { jvmTarget.set(org.jetbrains.kotlin.gradle.dsl.JvmTarget.JVM_[JAVA_VERSION]) }
}

dependencies {
    implementation(project(":domain"))
    
    // Framework-agnostic DI annotation
    implementation(libs.javax.inject)
    
    // Add Data layer libraries here: Room, Retrofit, DataStore, etc.
}
```

## 3. The `:app` Module (Android Framework, UI & DI Wiring)
**File**: `app/build.gradle.kts`
*(Usually generated by the IDE, but ensure these dependencies are present if refactoring)*
```kotlin
dependencies {
    implementation(project(":domain"))
    implementation(project(":data"))

    // Android, Compose, and DI Libraries (Hilt/Koin)
    // ...
}
```

## 4. Standard Module `.gitignore`
Every new module MUST have this file to prevent tracking build artifacts.
**File**: `<module-name>/.gitignore`
```text
/build
```
