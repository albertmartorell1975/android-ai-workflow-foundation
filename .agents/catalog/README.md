# Foundation Catalog

The catalog contains optional skills and workflow plugins that are not part of
the mandatory Foundation Core.

## Workflow Plugins

### DevExpert AI Workflow

**Provider:** Antonio Leiva / DevExpert  
**Course:** AI Expert

A complete agentic development workflow including:

- `build-brief`
- `harness-starter`
- `feature-spec`
- `feature-implementer`
- `feature-validator`
- `feature-flow`

When this workflow is active, `workflow-feature` must not be used for feature
orchestration.

## Optional Skills

Additional technology-specific and expert skills can be activated depending
on the project.
